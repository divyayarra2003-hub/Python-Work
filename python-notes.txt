input formatting:
---------------------

for string type: input()
for int type : int(input())
for float type: float(input())

split() function:
--------------------
it is for separation of string... it converts the string into list of elements whenever there is a space.

map() function:
-----------------
map is for conversion of numeric values either int or float. the output of the map is object, so we use list to get the output in list or tuple or set.
list(map(datatype, variable name))
Ex: list(map(int, values))

taking input from users:
-------------------------
str - input()
int - int(input())
float- float(input())

list of strings - list(input().split())
list of int - list(map(int, input().split()))
list of float - list(map(float, input().split())

tuple of strings - tuple(input().split())
tuple of int - tuple(map(int, input().split()))
tuple of float - tuple(map(float, input().split())

set of strings - set(input().split())
set of int - set(map(int, input().split()))
set of float - set(map(float, input().split())
