OOP Concepts – Short Notes with Examples
--------------------------------------------

1. Why do we use OOP?
--------------------
OOP (Object-Oriented Programming) is used to organize, reuse, secure, and maintain code easily, especially in large applications.
Example: A banking application can have separate objects for customers, accounts, and transactions.

2. Class
---------------
A class is a blueprint/template used to create objects. It defines the data and methods an object can have.
class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print(self.name)

3. Object
---------
An object is an instance of a class. We can create multiple objects from one class, each having its own data.
s1 = Student("John")
s2 = Student("David")
Here, s1 and s2 are objects of the Student class.

4. Encapsulation
-------------------
Encapsulation means wrapping data and methods together inside a class and restricting direct access to sensitive data. It provides data security.
Example: Instagram
Your password and private account information should not be directly accessible or modified by anyone.
class Instagram:
    def __init__(self, password):
        self.__password = password

__password is private and cannot be directly accessed from outside the class.

5. Inheritance
--------------------
Inheritance allows one class to acquire the properties and methods of another class. It helps with code reuse and extending/updating functionality.
Example:
class User:
    def login(self):
        print("Login")

class PremiumUser(User):
    def premium_features(self):
        print("Premium features")

PremiumUser inherits the login() method from User.

6. Polymorphism
---------------------
Polymorphism means one method or action can behave differently depending on the object.
Example: YouTube
Normal and Premium users can both use watch_video(), but the behavior can be different.

class User:
    def watch_video(self):
        print("Video with ads")

class PremiumUser:
    def watch_video(self):
        print("Video without ads")

Same method: watch_video()
Different behavior: with ads / without ads.

7. Abstraction
----------------------
Abstraction means hiding complex implementation details and showing only the necessary features to the user.
Example: Phone
When you make a call, you simply press the Call button. You don't need to know how the phone internally connects to the network.

Phone
 └── Call()
      ↓
   User sees: "Call"
   Hidden: Network connection, signal processing, etc.

1. Types of Attributes
---------------------------
There are mainly 2 types of attributes:

A. Instance Attribute
---------------------
Belongs to a specific object.
Each object can have different values.
Usually defined using self.
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
s1 = Student("John", 20)
s2 = Student("David", 22)

Here:

s1.name → John
s2.name → David

name and age are instance attributes.

B. Class Attribute
-----------------------
Belongs to the class.
Shared by all objects unless an object creates its own value.
class Student:
    college = "ABC College"

    def __init__(self, name):
        self.name = name
s1 = Student("John")
s2 = Student("David")

print(s1.college)  # ABC College
print(s2.college)  # ABC College

college is a class attribute.

Easy difference
Instance attribute → Different for each object
Class attribute     → Common/shared among objects

2. Types of Methods
----------------------
There are mainly 3 types of methods:

A. Instance Method
----------------------
Works with object/instance data.

It uses self.

class Student:
    def display(self):
        print("Student details")
s1.display()

Here, display() is an instance method.

B. Class Method
--------------------
Works with class-level data.

It uses cls and the @classmethod decorator.

class Student:
    college = "ABC College"

    @classmethod
    def change_college(cls, name):
        cls.college = name
Student.change_college("XYZ College")

change_college() is a class method.

C. Static Method
----------------------
Doesn't need either self or cls.

It is generally used for a utility operation related to the class.

class Calculator:

    @staticmethod
    def add(a, b):
        return a + b
print(Calculator.add(10, 20))

add() is a static method.

Quick Interview Table
---------------------
Type	                    Uses	                        Belongs to
Instance Attribute	        self	                        Object
Class Attribute	            cls / class name	            Class
Instance Method	            self	                        Object
Class Method	            cls	                            Class
Static Method	            Neither self nor cls	        Class namespace

Remember it simply:
--------------------

Attributes = Data

Instance attribute → Object-specific data
Class attribute → Common data

Methods = Behavior

Instance method → Works with object data
Class method → Works with class data
Static method → Independent utility function related to the class
